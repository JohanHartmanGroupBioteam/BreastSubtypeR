# PCAPAM50 1.0.4 locale reference fixture (#232)

`reference.rds` contains test-only expectations extracted from the completed
2026-11-03 investigation, not predictions generated by the implementation under
test. Standard tests read it offline and do not load or require PCAPAM50. Public
expression datasets and stored package results are not changed or duplicated.

  `8920f64bb7cc669c1cd1fe09370aaa6029877118`. This identifies the exact Git mirror
  source; it is not a new claim of canonical CRAN tarball identity.

  `917e5cb10e803edbc2f56b576a1074bef9912fde0d68b453553302af046a8da9`.

  LAPACK 3.12.1; SummarizedExperiment 1.43.0, dplyr 1.2.1, withr 3.0.3.
- Effective `LC_COLLATE`: `C` and `en_US.UTF-8`; other locale categories held
  constant. Seed 118; RNGkind Mersenne-Twister / Inversion / Rejection.
- Original IDs and synthetic IDs made by uppercasing even columns and
  lowercasing odd columns, before any permutation. Original, reversed and
  fixed-permuted inputs; the permutation was generated with seed 232 under

The original first stage received the exact expression matrix and complete,
character-ID IHC table prepared by the wrapper. The original second stage
received the original first stage's returned labels and character-key merge
order. Native original calls were observed immediately before return, preserving
its own exit handling. The native BreastSubtypeR functions were separately
observed without replacing calculations. All 12 paired comparisons agreed on
ordered selections, raw medians, centroid correlations and first/final five-class
calls (numerical differences zero for medians and correlations). The original's
file-roundtrip standardized expression differed by at most 2.80e-14 from the
equivalent standardized package matrix; those unlike exported matrix
representations are deliberately not compared as raw `testData`.

`extract-reference.R` checks immutable archive MD5 values, extracts only `REF.*`
traces and `ref1`/`ref2` results, and verifies that all three input orders give the
same expectation within each ID/locale combination. It does not run a classifier
or consult saved BreastSubtypeR predictions. The four compact cases retain both
ordered candidate lists, sampled indices, ordered selected identities, all 50 raw
medians, all 102 five-class calls and all 510 centroid correlations per stage.
Correlation dimnames are restored from the original prediction/centroid labels;
the original returned correlations already have the positive-correlation sign.
Clinical annotations, IDs and gene names come from the original's supplied input.

## Scope and portability

Tests require C collation and separately probe alternate UTF-8 locale spellings.
An unavailable alternate comparison is skipped without skipping C cases. A
successful switch must agree with the effective `Sys.getlocale("LC_COLLATE")`
and the complete mixed-case sample-ID collation sentinel, plus gene/ER ordering
sentinels. An available but incompatible collation profile fails explicitly; it
is not silently treated as this reference or skipped. Scoped locale changes are
for tests only and are restored on success and error. No package locale forcing,
case normalization or deterministic-sort substitution is introduced.

Candidate lists, sampled indices, selected identities, metadata and calls are
exact expectations. Numerical medians and correlations use an explicit absolute
1e-10 tolerance, not bitwise identity: this permits double-precision arithmetic
and BLAS/platform differences while being much smaller than the observed
scientific effects (median maxima about 1.28 and 0.73 across locales). The retained
minimum oriented-PC1 distance to any cutoff-search grid point is 7.54e-4, to the
chosen cutoff 0.259, and minimum winning/runner-up correlation gap across both
stages and all cases is 5.76e-4. Thus roundoff at the allowed scale does not justify
changing these discrete expectations. PCA vectors are not frozen: SVD sign and
last-bit differences are not portable or biologically meaningful. Unexpected
candidate/rank/call changes must be investigated, not hidden by larger tolerances.
Whole-output permutation comparisons allow testthat's 1e-10 numerical tolerance;
call tables remain exact. Repeated identical executions within one process are
expected to be identical. This does not assert universal input-order invariance.

There are 24 reference-grid executions: two ID schemes x three input orders x
two PatientID encodings (character and reversed factor levels with unused levels)
x two locale profiles, if the alternate is available. Both stages are observed;
all returned sample axes and clinical payloads are checked. Separate uninstrumented
runs test fixed-seed repetition, caller RNG present/absent, Mersenne-Twister and
L'Ecuyer-CMRG, and caller state after success and a real post-calculation error.
Only the former RNGkind has original-reference call expectations. Existing
independent Parker formula tests check clinical ROR alignment, without implying
that all package ROR extensions or four-class outputs were supplied by the
original reference.

Original IDs gave identical cross-locale calls in this fixture. Mixed IDs gave
three LumA-to-LumB changes from C to UTF-8: `oslo2emit0.019`, `OSLO2EMIT0.093`,
`OSLO2EMIT0.097`. The first selected sets share 17/32 identities and the second
16/26. Tests protect the two per-locale reference outcomes; they do not require
universal cross-locale equality or universal three-call differences. The earlier
1.5.4 reproduction is historical evidence, not the expected-value source here.
