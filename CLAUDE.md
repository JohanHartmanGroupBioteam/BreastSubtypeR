# Contributor policy for AI-assisted work

- Never add Claude, Claude Code, or any AI assistant as a contributor,
  author, or co-author of this repository.
- Do not add `Co-Authored-By` trailers naming Claude or Claude Code to
  commit messages, and do not add `Claude-Session` or similar trailers.
- Do not add Claude or Claude Code to `Authors@R` in `DESCRIPTION`, to
  `inst/CITATION`, or to any contributor list in the README, NEWS, or
  vignettes.
- Do not add "Generated with Claude Code" footers or session links to
  pull request descriptions.

Commits and pull requests are authored by the human maintainers only.
